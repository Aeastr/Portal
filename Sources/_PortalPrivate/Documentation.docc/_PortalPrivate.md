# ``_PortalPrivate``

Mirror SwiftUI content through Apple's private `_UIPortalView` implementation.

@Options {
    @TopicsVisualStyle(detailedGrid)
}

## Overview

This module can preserve a live view during a transition, but private API use can break across iOS releases and may lead to App Store rejection. Review the limitations before adopting it.
